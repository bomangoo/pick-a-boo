# Pick-a-Boo 🍓🎈

일러스트 페어 현장용 **따뜻한 선물 뽑기 게임**입니다. 아이패드(가로, 4:3)와 키 6개(방향키 4개 + A + B)로 플레이합니다.

## 게임 두 가지

| | 🍓 딸기밭에 물 주기 | 🎈 열기구 세계여행 |
|---|---|---|
| 이야기 | 루샤의 작은 딸기밭에서 선물을 키워요 | 세계 곳곳의 친구에게 놀러 가요 |
| 조작 | 걸어가서 흙더미 앞에서 Ⓐ | 열기구를 몰아 섬 근처에서 Ⓐ |
| 연출 | 물 주기 → 새싹 → 꽃 → 선물이 자라남 | 착륙 → 친구와 인사 → 선물 상자 개봉 |
| 결과 | 루샤가 보낸 엽서 | 친구가 보낸 엽서 |

한 판은 30~40초 정도 걸립니다. 결과는 **엽서**로 나오고, 엽서 한쪽에 인스타 QR이 들어가 있습니다.

## 상품 / 확률

- 1등 1, 2등 3, 3등 10, 4등 20, 5등 50개이고 **꽝은 없습니다**(총 84명).
- **남은 수량에 비례해서** 뽑기 때문에 정해진 수량보다 더 나가지 않습니다.
- 재고는 아이패드 브라우저(localStorage)에 저장되어 새로고침해도 유지됩니다.

## 키

| 키 | 동작 |
|---|---|
| ◀ ▲ ▼ ▶ | 이동 / 고르기 |
| Ⓐ = Space · Enter · Z | 확인 / 행동 / 대화 넘기기 |
| Ⓑ = Esc · Backspace · X | 뒤로 |

키패드 매핑이 다르면 `src/config.js` 의 `KEYMAP` 에 키 코드를 추가하세요. 화면을 탭하면 Ⓐ 와 같게 동작합니다.

## 스태프 메뉴

처음 화면에서 **Ⓑ 를 3초 꾹** 누르면 열립니다.

- 등수별 남은 수량 조절 (◀ ▶)
- 소리 켜기/끄기
- 전체 초기화 (Ⓐ 3초 꾹)
- 오늘 기록 / 최근 결과 확인

## 바꿔야 할 것

`src/config.js` 에서 수정합니다.

- `instagramHandle`, `instagramUrl`: 지금은 예시 값(`@lushaa`)입니다. **실제 계정으로 꼭 바꿔주세요.** QR이 이 주소로 만들어집니다.
- `heroName`: 주인공 이름 (현재 `루샤`)
- `PRIZE_STOCK`: 등수별 수량
- `RESULT_TIMEOUT` / `IDLE_TIMEOUT`: 결과 화면·방치 시 처음으로 돌아가는 시간

상품 이름과 대사는 `src/story.js` 에 있습니다.

## 일러스트 교체

`public/assets/sprites/` 의 PNG는 받은 일러스트에서 배경을 지워 잘라낸 **임시 파일**입니다. 같은 파일명으로 고해상도 투명 PNG를 덮어쓰면 그대로 반영됩니다. 높이는 코드에서 맞추기 때문에 크기는 자유롭게 넣어도 됩니다.

## 실행 / 배포

```bash
npm install
npm run dev      # 개발 서버 (같은 와이파이의 아이패드에서 http://<PC IP>:5173 접속)
npm run build    # dist/ 생성 → 아무 정적 호스팅(GitHub Pages, Netlify 등)에 올리면 됨
```

아이패드 사파리에서 연 뒤 **공유 → 홈 화면에 추가**로 실행하면 주소창 없이 전체화면으로 뜹니다. 한 번 열어두면 오프라인 캐시가 되어 현장 와이파이가 끊겨도 동작합니다.

## GitHub Pages 배포

`.github/workflows/deploy.yml` 이 브랜치에 푸시될 때마다 자동으로 빌드해서 배포합니다.

1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다 (처음 한 번만).
2. **Actions** 탭에서 `Deploy to GitHub Pages` 가 초록색이 되면 `https://bomangoo.github.io/pick-a-boo/` 에서 열립니다.
3. 첫 배포가 Source 설정 전에 실패했다면 Actions 탭에서 **Run workflow** 로 다시 실행하세요.
